# Rodrigo Miranda | Advocacia de trânsito

Site institucional de Rodrigo Miranda, com atuação em recursos de multas e processos de trânsito. Página única, rápida e responsiva, pensada para levar o visitante das informações principais ao contato pelo WhatsApp.

## Destaques

- Layout responsivo para celular, tablet e computador
- Animações de rolagem e de mouse, com suporte à preferência de movimento reduzido do sistema
- Páginas estáticas, sem banco de dados ou login
- Dados estruturados para mecanismos de busca (schema.org)

## Tecnologias

- [Astro](https://astro.build)
- CSS e JavaScript puros
- [Fontsource](https://fontsource.org) (Playfair Display e Inter)

## Rodando localmente

Requer [Node.js](https://nodejs.org).

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
